<objective>
Compute cross-camera board-localization agreement (MET-03) over the 8 held-out validation
frames, in the RAW MVS frame, BEFORE any rigid/scale alignment.

For each (frame_idx, corner_id) co-observed by >= 2 depth cameras, compare the 3-D positions
each camera's depth INDEPENDENTLY places that corner at, and report the dispersion (RMS distance
of the per-camera points to their centroid), aggregated per frame and overall, in mm.

This is an internal consistency check on the dense depth — it needs no ground truth and is
scale-independent. It quantifies whether each camera's depth places the transferred corners at a
consistent 3-D location.

Purpose: One of the three headline non-circular numbers. RIG FACT: the array images a volume
larger than any single camera's FOV, so each board pose is seen by only a SUBSET of cameras;
per-(frame,camera) corner counts vary by design (0, 2, 12, 52...). A camera that sees nothing is
a non-event, not a dropout — agreement is measured ONLY among co-observing cameras, with a
coverage threshold to drop meaningless glimpses.
Output: analysis/cross_camera.py, analysis/compute_cross_camera.py, a reloadable JSON artifact
(+ schema sidecar), and synthetic unit tests.
</objective>

  <action>
Create analysis/cross_camera.py with pure-numeric, dataset-free functions (unit-testable on
synthetic data). Distances returned in mm.

1. `load_corners(npz_path) -> dict` of arrays (frame_idx, camera_id, corner_id, points) using
   np.load(allow_pickle=True). camera_id/method may be object arrays — cast camera_id to str.
2. `per_camera_coverage(frame_idx, camera_id, frame) -> dict[str,int]`: count corners contributed
   by each camera in that frame (the basis for the coverage threshold).
3. `included_cameras(coverage, min_corners) -> (included:set[str], excluded:dict[str,int])`:
   cameras with count >= min_corners are included; the rest recorded as excluded with their counts.
   This is what enforces "ignore 2-corner glimpses" and "never treat a board-blind camera as error".
4. `per_corner_dispersion(points_by_camera) -> dict`: given a mapping camera->(3,) point for ONE
   (frame,corner) where len >= 2, compute centroid = mean of points, and
   rms_mm = sqrt(mean(||p_i - centroid||^2)) * 1000.0. Return
   {rms_mm, n_cameras, max_pairwise_mm}. (max_pairwise_mm = max Euclidean distance between any two
   camera points, in mm — a useful secondary stat.)
5. `frame_agreement(corners_for_frame, included_cams, min_cameras=2) -> dict`: restrict to included
   cameras, group rows by corner_id, keep only corner_ids co-observed by >= min_cameras INCLUDED
   cameras, compute per_corner_dispersion for each, and aggregate to a per-frame value:
   frame_rms_mm = sqrt(mean(per_corner rms_mm**2)) over the co-observed corners (and also report
   n_corners_compared, n_cameras_included, mean/median per-corner rms_mm). If no corner is
   co-observed by >= 2 included cameras, return frame_rms_mm = NaN with n_corners_compared = 0.

Create tests/test_cross_camera.py as a plain-assert script (NO pytest dependency) with an
`if __name__ == "__main__":` block that runs all checks and prints "test_cross_camera OK":
  - per_corner_dispersion on two cameras 10 mm apart -> rms_mm ~= 5.0, max_pairwise_mm ~= 10.0.
  - per_corner_dispersion on >= 3 cameras at a known spread -> matches the closed-form RMS.
  - included_cameras with counts {A:52, B:12, C:2} and min_corners=6 -> included {A,B}, excluded {C:2}.
  - frame_agreement: synthesize a frame where camera C (a 2-corner glimpse) is excluded and does NOT
    affect frame_rms_mm; and a corner seen by only ONE included camera is skipped (not counted as error).
  - A board-blind camera (0 rows) simply never appears -> no error contribution.
Use only numpy.
