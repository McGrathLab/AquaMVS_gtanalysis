<objective>
Compute the two dense/sparse scale-independent metrics — board flatness (MET-01) and
spatial/angular consistency (MET-02) — over the 8 held-out validation frames, in the
RAW MVS frame, BEFORE any rigid/scale alignment to the ideal board.

MET-01: fit a plane to each frame's dense board points and report the RMS of
point-to-plane residuals (per frame + pooled), in mm. Robust fit: RANSAC to reject
outliers, then SVD/total-least-squares refit on inliers.

MET-02: per frame record board centroid (XY + rig depth), tilt (fitted-plane-normal
angle), flatness RMS, and a board size measure; then report how flatness and size
VARY across the working volume (vs depth, lateral position, tilt) — framed as
consistency, not absolute accuracy (absolute size is the partly-circular MET-04 in Phase 4).

Purpose: These are the headline non-circular accuracy numbers. The ordering invariant
is structural — no scale/pose fit to the ideal board may run before these are recorded,
or it could absorb the very error being measured.
Output: analysis/flatness.py, analysis/compute_flatness_consistency.py, a reloadable
JSON artifact (+ schema sidecar), and synthetic unit tests.
</objective>

  <action>
Create analysis/flatness.py with pure-numeric, dataset-free functions (so they are unit-testable
with synthetic data):

1. `robust_plane_fit(points3d, dist_threshold=0.002, n_iters=200, min_inlier_frac=0.5, seed=0)
    -> dict` with keys: `point` (3,), `normal` (3,), `inlier_mask` (M,) bool, `rms_mm` (float),
    `n_inliers` (int), `n_points` (int).
    - RANSAC: repeatedly sample 3 non-collinear points, build a candidate plane, count inliers
      within `dist_threshold` metres of the plane (point-to-plane |signed distance|).
    - Take the best inlier set, then REFIT the plane on those inliers via the existing
      `analysis.corner_transfer.fit_board_plane` (SVD/total-least-squares).
    - `rms_mm` = sqrt(mean(signed_dist_inliers**2)) * 1000.0  (metres -> mm).
    - Degenerate guard: if < 3 points or fit_board_plane returns None, return a dict with
      `normal=None`, `rms_mm=float('nan')`, `n_inliers=0`.
2. `plane_tilt_deg(normal, reference)` -> float: angle in DEGREES between the fitted plane
    normal and a reference direction (caller passes calib.interface_normal). Sign-agnostic:
    use abs(dot) so flipping the normal does not change the angle; clamp to [-1,1] before arccos.
3. `board_size_from_corners(corner_ids, points_xyz, board_spec)` -> dict with keys
    `size_mm` (float) and `n_pairs` (int): map each ChArUco corner_id to its (row,col) on the
    11x8 internal-corner grid (cols = squares_x-1 = 11, rows = squares_y-1 = 8; corner_id =
    row*11 + col), then measure the median 3-D distance between horizontally- and
    vertically-adjacent corner pairs and convert to mm. This estimates the reconstructed square
    edge length. Return NaN size_mm if fewer than 1 adjacent pair is available.
    NOTE in the docstring: MET-02 uses this as a CONSISTENCY (variation) measure across frames,
    NOT an absolute-accuracy check — absolute size correctness is the partly-circular MET-04 (Phase 4).

Create tests/test_flatness.py as a plain-assert script (NO pytest dependency) with an
`if __name__ == "__main__":` block that runs all checks and prints "test_flatness OK":

  - Build a synthetic 11x8 grid spaced exactly 0.06 m on a tilted plane; assert
