- Step 1: Check if data root already exists — if `./data/aquamvs_ground_truth_analysis/calibration.json` already exists, skip extraction and go straight to manifest check (idempotent re-run)

    - `depth_maps/` subdirectory exists AND contains exactly 12 `.npz` files (each non-zero)
