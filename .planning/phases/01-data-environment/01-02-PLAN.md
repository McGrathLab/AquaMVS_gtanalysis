### aquamvs.calibration — USE THIS for camera/interface loading

```python
from aquamvs.calibration import load_calibration_data, CalibrationData, CameraData

# Returns CalibrationData dataclass:
#   cameras: dict[str, CameraData]  — 13 cameras including e3v8250
#   water_z: float
#   interface_normal: torch.Tensor  shape (3,) float32
#   n_air: float
#   n_water: float
#
# CameraData fields: name, K (3,3), dist_coeffs, R (3,3), t (3,), image_size, is_fisheye, is_auxiliary
calib = load_calibration_data("data/aquamvs_ground_truth_analysis/calibration.json")
```

CalibrationData.ring_cameras → non-auxiliary cameras (sorted).
CalibrationData.auxiliary_cameras → auxiliary cameras (sorted).

### Board spec — parse from calibration.json directly

`aquamvs.calibration.load_calibration_data` wraps `aquacal.io.serialization.load_calibration`
and does NOT expose board params. Parse board fields from `calibration.json` manually
using `json.load`. During execution, inspect the JSON keys to find:
- square_size (expect 0.06)
- marker_size (expect 0.045)
- board dimensions (expect 12×9 or similar keys)
- dictionary name (expect DICT_5X5_100 or an enum value)

If board spec is nested (e.g., under a "board" key), navigate accordingly.
If keys differ from expectation, use the actual values found and note them in SUMMARY.

### aquamvs.io — NOT needed for this loader

ImageDirectorySet is for reading raw frame sequences — irrelevant here since
the extracted data already has pre-computed depth maps, undistorted images, and clouds.

```python
# analysis/loader.py

from dataclasses import dataclass
from pathlib import Path
from typing import Optional
import json
import numpy as np
from aquamvs.calibration import load_calibration_data, CalibrationData

# ── Constants ───────────────────────────────────────────────────────────────

DEFAULT_DATA_ROOT = Path("data/aquamvs_ground_truth_analysis")

# Output indices 0 and 5 coincide with calibration-fit frames
CALIBRATION_OVERLAP_INDICES: frozenset[int] = frozenset({0, 5})

# Camera that has frames but NO depth map .npz
NO_DEPTH_CAMERAS: frozenset[str] = frozenset({"e3v8250"})

# ── Dataclasses ─────────────────────────────────────────────────────────────

@dataclass(frozen=True)
class BoardSpec:
    """ChArUco board geometry from calibration.json."""
    squares_x: int          # 12
    squares_y: int          # 9
    square_size: float      # 0.06 m
    marker_size: float      # 0.045 m
    dict_name: str          # "DICT_5X5_100"

@dataclass(frozen=True)
class DatasetConfig:
    """Configurable dataset root. Defaults to repo-relative data path."""
    data_root: Path = DEFAULT_DATA_ROOT

@dataclass(frozen=True)
class FrameInfo:
    """Per-output-index metadata. Does NOT load data eagerly."""
    output_idx: int              # 0–9
    raw_frame_idx: int           # actual video frame number
    is_calibration_overlap: bool # True for indices 0 and 5

# ── Main class ───────────────────────────────────────────────────────────────

class GroundTruthDataset:
    def __init__(self, config: DatasetConfig = DatasetConfig()): ...

    # Calibration (cached after first call)
    def calibration(self) -> CalibrationData: ...

    # Board spec parsed from calibration.json (cached)
    def board_spec(self) -> BoardSpec: ...

    # All 10 frames including calibration-overlap; ordered by output_idx
    def all_frames(self) -> list[FrameInfo]: ...

    # 8 held-out frames only (output indices 1,2,3,4,6,7,8,9)
    def validation_frames(self) -> list[FrameInfo]: ...

    # Depth map — returns None for e3v8250 or missing file; no crash
    def depth_map_path(self, frame: FrameInfo, camera: str) -> Optional[Path]: ...
    def load_depth_map(self, frame: FrameInfo, camera: str) -> Optional[np.ndarray]: ...

    # Fused cloud — Path only, NOT loaded
    def fused_cloud_path(self, frame: FrameInfo) -> Path: ...

    # Undistorted image path for a camera + frame
    def undistorted_image_path(self, frame: FrameInfo, camera: str) -> Path: ...

    # Private helpers
    def _output_dir(self, frame: FrameInfo) -> Path: ...
```
</interfaces>

**3. Write `analysis/loader.py`**

Implement `GroundTruthDataset` per the interface spec in `<interfaces>` above. Key rules:

- `__init__`: store config, set `_calib_cache = None`, `_board_spec_cache = None`
- `calibration()`: call `load_calibration_data(config.data_root / "calibration.json")` on first call, cache result
- `board_spec()`: open `config.data_root / "calibration.json"` with `json.load`, extract board fields using the actual key names found in the inspection step, return `BoardSpec(squares_x=12, squares_y=9, square_size=0.06, marker_size=0.045, dict_name="DICT_5X5_100")` (or whatever the actual values are). Cache the result.
- `all_frames()`: return 10 `FrameInfo` objects. Raw frame indices are: [0, 786, 1572, 2358, 3144, 3930, 4716, 5502, 6288, 7074] (output index = list position). is_calibration_overlap is True for output indices 0 and 5.
- `validation_frames()`: filter `all_frames()` to output_idx NOT in CALIBRATION_OVERLAP_INDICES
- `_output_dir(frame)`: return `config.data_root / "output" / f"frame_{frame.output_idx:06d}"`
- `depth_map_path(frame, camera)`: if camera in NO_DEPTH_CAMERAS return None; build path `_output_dir(frame) / "depth_maps" / f"{camera}.npz"`; if file doesn't exist return None; else return the Path
- `load_depth_map(frame, camera)`: call `depth_map_path`; if None return None; load with `np.load(path)` and return the array (inspect the npz key during execution — likely "depth" or the first key in the archive). If loading fails log a warning and return None.
- `fused_cloud_path(frame)`: return `_output_dir(frame) / "point_cloud" / "fused.ply"` — do NOT load the file
- `undistorted_image_path(frame, camera)`: return `_output_dir(frame) / "undistorted" / f"{camera}.png"`

Include module-level `logger = logging.getLogger(__name__)` and log key events (cache hit, depth map missing, etc.) at DEBUG level.

Add a `__repr__` to `GroundTruthDataset` showing data_root and frame count.
