Create `analysis/alignment.py` — a pure-numeric, dataset-free module (mirror the header/style of analysis/flatness.py and analysis/cross_camera.py, including the `sys.path.insert(0, repo_root)` shim and an ORDERING INVARIANT docstring stating these functions run AFTER Phase 3 and write nothing).

Implement, all closed-form (write directly — do NOT call icp_align as primary; corner_id correspondence is known):

1. `umeyama_fit(src, dst, with_scale: bool) -> dict` — closed-form Kabsch/Umeyama for KNOWN one-to-one correspondence between (N,3) `src` and (N,3) `dst`. Algorithm:
     mu_s = src.mean(0); mu_d = dst.mean(0)
     Xs = src - mu_s; Xd = dst - mu_d
     Sigma = (Xd.T @ Xs) / N
     U, D, Vt = np.linalg.svd(Sigma)
     S = eye(3); if det(U)*det(Vt) < 0: S[2,2] = -1     # reflection guard
     R = U @ S @ Vt
     if with_scale: var_s = (Xs**2).sum()/N; s = float((D * np.diag(S)).sum() / var_s)
     else:          s = 1.0
     t = mu_d - s * (R @ mu_s)
   Compute residual vectors `res = dst - (s*(R@src.T).T + t)`, per-corner residual norm in mm
   (`np.linalg.norm(res,axis=1)*1000`), and `rms_mm = sqrt(mean(sum(res**2,axis=1)))*1000`.
   Return dict: {s, R (3,3), t (3,), rms_mm, per_corner_residual_mm (N,), n}.
   Convention: `src` = ideal board (metres), `dst` = consensus MVS corners (metres); then `s` is
   reconstructed/ideal scale ratio so scale_error = s - 1 (>0 means reconstruction larger than ideal).
   Guard N < 3 -> return dict with rms_mm = nan, s = nan, etc.

2. `rigid_inlier_fit(src, dst, abs_thresh_mm: float = 5.0, mad_k: float = 3.0, min_inliers: int = 3) -> dict`
   — MET-05 driver: first fit `umeyama_fit(with_scale=False)` on ALL matched corners, take
   per_corner_residual_mm, reject gross outliers (keep corners with residual <=
   max(abs_thresh_mm, median + mad_k*MAD), where MAD = median(|r - median(r)|)), then REFIT
   `umeyama_fit(with_scale=False)` on the inlier subset. Return {rms_mm (inlier), n_inliers,
   n_total, inlier_mask (N,) bool, s, R, t}. If inliers < min_inliers, return the all-corner fit
   with a flag `degenerate: True`. (Outlier rule/threshold is Claude's discretion — document the
   chosen defaults in the docstring; defaults above are a reasonable starting point.)

3. `build_consensus_corners(frame_idx, camera_id, corner_id, points_xyz_m, frame: int) -> dict[int, np.ndarray]`
   — for one frame, defensively keep only finite & Z>0 rows, group rows by corner_id across the
   co-observing cameras, and average their (X,Y,Z) into ONE consensus point per corner_id (metres).
   Returns {corner_id: (3,) float64}.

4. `ideal_board_corners(board) -> np.ndarray` — thin wrapper returning
   `board.get_opencv_board().getChessboardCorners().astype(float64)` (88,3) board-local metres.

5. `matched_arrays(consensus: dict[int,np.ndarray], ideal_all: np.ndarray) -> tuple[ids, src_ideal, dst_consensus]`
   — for the sorted corner_ids present in `consensus`, return matched (N,3) `src` = ideal_all[ids]
   and (N,3) `dst` = stacked consensus points.

Then create `tests/test_alignment.py` (stdlib only, mirror tests/test_flatness.py structure: plain
asserts, `if __name__ == "__main__":` runs all tests and prints OK). Cover:
  - Exact recovery: build random R, t, scale; src=random points, dst = s*R@src + t; assert
    umeyama_fit(with_scale=True) recovers s within 1e-6 and rms_mm ~ 0; with_scale=False recovers
    R,t and rms_mm ~ 0 when s==1.
  - Pure rotation+translation (no scale): assert with_scale=False gives rms_mm < 1e-6.
  - Outlier rejection: take a clean matched set, corrupt 2 corners by +50 mm; assert
    rigid_inlier_fit excludes exactly those 2 (inlier_mask False there) and inlier rms_mm < 1 mm.
  - Scale-error sign: scale dst by 1.01; assert recovered s ~ 1.01 (scale_error ~ +0.01).
