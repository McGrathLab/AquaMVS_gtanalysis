<objective>
Place each detected ChArUco corner as a 3D point in the MVS world frame by bilinearly sampling the camera's depth map at the corner pixel and back-projecting through the refractive model — exactly as fusion places the dense cloud. Corners whose depth is missing/weak fall back to the fitted board plane. Persist the corner set and a per-frame/per-camera dropout report.

Purpose: XFER-02 (depth-based refractive transfer), XFER-03 (plane-fit fallback), XFER-04 (dropout reporting). This is the core deliverable of Phase 2; Phases 3-4 consume the persisted corners directly.
Output: `analysis/projection.py`, `analysis/corner_transfer.py`, `analysis/transfer_corners.py`, plus the persisted corners artifact + dropout report under the analysis output area.
</objective>

  <name>Task 2: Corner transfer with confidence gating and plane-fit fallback</name>
  <files>analysis/corner_transfer.py</files>
  <action>
Create `analysis/corner_transfer.py` implementing the per-(frame,camera) transfer with the direct-depth-first / plane-fit-fallback order from the CONTEXT.

Define:
- `@dataclass CornerRecord`: `frame_idx:int, camera_id:str, corner_id:int, point_3d:tuple[float,float,float], method:str, confidence:float, pixel:tuple[float,float]`. `method` is `"direct"` or `"plane_fit"`.
- `DEFAULT_MIN_CONFIDENCE = 0.1` (matches aquamvs config default).
- `fit_board_plane(points3d) -> tuple[np.ndarray, np.ndarray] | None`: fit a plane to (M,3) points via SVD/total-least-squares (centroid + smallest-singular-vector normal). Return `(point_on_plane, unit_normal)` or None if `M < 3`. (RANSAC is acceptable but SVD is sufficient — Claude's discretion per CONTEXT.) This is the fitter applied to the cropped fused-cloud slab.
- `intersect_ray_plane(origin, direction, plane_point, plane_normal) -> np.ndarray | None`: standard ray-plane intersection; return the 3D point, or None if the ray is parallel (|dot| < 1e-9).
- `board_pose_seed(detection, model, board, calib, camera, direct_pts=None) -> tuple[np.ndarray, np.ndarray] | None`: produce a COARSE seed plane `(point_world, normal_world)` used only to locate the slab. Preferred: ChArUco->PnP — `cv2.solvePnP(board.get_opencv_board().getChessboardCorners()[detection.corner_ids], detection.corners_2d, K_new, None)`; convert the board-local plane (board z=0, normal +z) to the world frame. (PnP through the refractive interface is approximate — fine for a crop seed.) Fallback when PnP fails or <4 corners: if `direct_pts` has >=3 points, seed via `fit_board_plane(direct_pts)`; else return None.
- `crop_cloud_to_slab(cloud_xyz, plane_point, plane_normal, thickness) -> np.ndarray`: signed distance of each (M,3) point to the seed plane = `(cloud_xyz - plane_point) @ plane_normal`; keep points with `|dist| <= thickness/2`. Return the (K,3) dense board-surface points.
- `transfer_frame_camera(ds, model, frame, camera, detection, board, calib, min_confidence=DEFAULT_MIN_CONFIDENCE, fused_cloud_points=None, slab_thickness=0.012) -> tuple[list[CornerRecord], dict]`:
  1. `pixels = detection.corners_2d` (N,2), `ids = detection.corner_ids`.
  2. Load depth+confidence: `npz = np.load(ds.depth_map_path(frame,camera)); depth=npz["depth"]; conf=npz["confidence"]`.
  3. `d = sample_map_bilinear(depth, pixels)`, `c = sample_map_bilinear(conf, pixels)` (import from analysis.projection).
  4. Valid-direct mask: `np.isfinite(d) & (d > 0) & np.isfinite(c) & (c >= min_confidence)`.
  5. Direct corners: `pts = back_project(model, pixels[valid], d[valid])`; emit CornerRecord(method="direct", confidence=c_i) for each. Keep these direct 3D points around (`direct_pts`) for the seed fallback only.
  6. Fallback plane (computed ONLY if at least one corner is invalid) — fit from the FUSED DENSE CLOUD per the locked CONTEXT method, NOT from the direct corners:
     a. Seed: `seed = board_pose_seed(detection, model, board, calib, camera, direct_pts=direct_pts)` (ChArUco->PnP board pose, direct-corner SVD as fallback). This only locates the board.
     b. Get the fused cloud points: use `fused_cloud_points` if the caller passed them (Task 3 loads once per frame); otherwise lazily `cloud_xyz = np.asarray(o3d.io.read_point_cloud(str(ds.fused_cloud_path(frame))).points)`. The cloud is in the SAME world frame as the back-projected corners.
     c. `slab = crop_cloud_to_slab(cloud_xyz, *seed, slab_thickness)` (slab thickness ~5-15 mm, Claude's discretion; default 12 mm).
     d. `plane = fit_board_plane(slab)` — this fused-cloud slab fit is the PRIMARY plane used for EVERY plane_fit corner in this (frame,camera).
     e. Degraded fallback: if `seed is None`, or the cloud is unavailable, or `len(slab) < 3` / `plane is None`, try `plane = fit_board_plane(direct_pts)` (direct corners) as a last resort; if that is also None, no plane exists — count the dropped corners as unrecoverable and emit no record for them.
  7. For each invalid corner: back-project its ray with `model.cast_ray`, intersect with `plane` via intersect_ray_plane, emit CornerRecord(method="plane_fit", confidence = sampled c_i if finite else nan). (Skip corners only when no plane could be fit at all.)
  8. Return (records, counts) where counts = {"n_detected":N, "n_direct":..., "n_plane_fit":..., "n_unrecovered":...}.

Order matters: direct depth at the junction first; plane-fit (from the fused-cloud slab) only where direct is missing/weak (matches §3.2 then §3.3). Import open3d as o3d and cv2 at module top.
