<objective>
Place each detected ChArUco corner as a 3D point in the MVS world frame by bilinearly sampling the camera's depth map at the corner pixel and back-projecting through the refractive model — exactly as fusion places the dense cloud. Corners whose depth is missing/weak fall back to the fitted board plane. Persist the corner set and a per-frame/per-camera dropout report.

Purpose: XFER-02 (depth-based refractive transfer), XFER-03 (plane-fit fallback), XFER-04 (dropout reporting). This is the core deliverable of Phase 2; Phases 3-4 consume the persisted corners directly.
Output: `analysis/projection.py`, `analysis/corner_transfer.py`, `analysis/transfer_corners.py`, plus the persisted corners artifact + dropout report under the analysis output area.
</objective>

```python
K_new = compute_undistortion_maps(cam).K_new        # cam: CameraData; K_new is the POST-undistortion intrinsic
model = RefractiveProjectionModel(
    K=K_new, R=cam.R, t=cam.t,

```

  <name>Task 2: Corner transfer with confidence gating and plane-fit fallback</name>
  <files>analysis/corner_transfer.py</files>
  <action>
Create `analysis/corner_transfer.py` implementing the per-(frame,camera) transfer with the direct-depth-first / plane-fit-fallback order from the CONTEXT.

Define:
- `@dataclass CornerRecord`: `frame_idx:int, camera_id:str, corner_id:int, point_3d:tuple[float,float,float], method:str, confidence:float, pixel:tuple[float,float]`. `method` is `"direct"` or `"plane_fit"`.
- `DEFAULT_MIN_CONFIDENCE = 0.1` (matches aquamvs config default).
- `fit_board_plane(points3d) -> tuple[np.ndarray, np.ndarray] | None`: fit a plane to (M,3) points via SVD/total-least-squares (centroid + smallest-singular-vector normal). Return `(point_on_plane, unit_normal)` or None if `M < 3`. (RANSAC is acceptable but SVD on the board corners is sufficient — Claude's discretion per CONTEXT.)
- `intersect_ray_plane(origin, direction, plane_point, plane_normal) -> np.ndarray | None`: standard ray-plane intersection; return the 3D point, or None if the ray is parallel (|dot| < 1e-9).
- `transfer_frame_camera(ds, model, frame, camera, detection, min_confidence=DEFAULT_MIN_CONFIDENCE) -> tuple[list[CornerRecord], dict]`:
  1. `pixels = detection.corners_2d` (N,2), `ids = detection.corner_ids`.
  2. Load depth+confidence: `npz = np.load(ds.depth_map_path(frame,camera)); depth=npz["depth"]; conf=npz["confidence"]`.
  3. `d = sample_map_bilinear(depth, pixels)`, `c = sample_map_bilinear(conf, pixels)` (import from analysis.projection).
  4. Valid-direct mask: `np.isfinite(d) & (d > 0) & np.isfinite(c) & (c >= min_confidence)`.
  5. Direct corners: `pts = back_project(model, pixels[valid], d[valid])`; emit CornerRecord(method="direct", confidence=c_i) for each.
  6. Fallback: fit the board plane from the DIRECT 3D corners (the dense board points the depth map placed). If fewer than 3 direct corners exist for this (frame,camera), instead crop the fused dense cloud to a thin slab around those few points (or around the camera's depth-derived board region) and fit from that — load the cloud lazily via `ds.fused_cloud_path(frame)` only in this rare branch; slab thickness is Claude's discretion (~5-15 mm). If no plane can be fit at all, record the dropped corners with method="plane_fit" only if a plane exists; otherwise skip and count them as unrecoverable.
  7. For each invalid corner: back-project its ray with `model.cast_ray`, intersect with the fitted plane via intersect_ray_plane, emit CornerRecord(method="plane_fit", confidence = sampled c_i if finite else nan).
  8. Return (records, counts) where counts = {"n_detected":N, "n_direct":..., "n_plane_fit":..., "n_unrecovered":...}.

Order matters: direct depth at the junction first, plane-fit only where direct is missing/weak (matches §3.2 then §3.3).
